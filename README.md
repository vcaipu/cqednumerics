# Superconductors with Nonrelativistic Scalar Electrodynamics

## Get Started

Get the dependencies as a Python Virtual Env (need CUDA if want to run with GPU)
```bash
python3 create_venv.sh
```

May need to run:

```bash
pip uninstall -y jax jaxlib
PIP_NO_COMPILE=1 pip install "jax==0.4.30" "jaxlib==0.4.30"
```
